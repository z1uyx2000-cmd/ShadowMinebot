# TG-Auth Bot

## Установка

1. Установите Python 3.10+
2. В папке проекта выполните:
   ```
   pip install -r requirements.txt
   ```
3. Откройте `config.py` и вставьте свой токен от @BotFather:
   ```python
   BOT_TOKEN = "ваш_токен_сюда"
   ```
4. Запустите бота:
   ```
   python bot.py
   ```

## Команды бота

- `/start` — приветствие и инструкция
- `/help` — список команд
- `/tg НИК ПАРОЛЬ` — привязать игровой ник к Telegram-аккаунту
- `/list` — список привязанных ников
- `/recovery НИК` — сбросить пароль (только для своих привязанных ников)

## База данных

Создаётся автоматически в файле `tgauth.db` (SQLite) при первом запуске.
Таблица `links`: nickname, chat_id, password_hash, created_at.

Пароли хранятся в виде SHA-256 хэша — это важно учесть при написании
Minecraft-плагина: он должен хэшировать введённый пароль так же
(`MessageDigest.getInstance("SHA-256")`), чтобы сверять с базой.

## Дальше

Когда бот будет протестирован — переходим к Java-плагину для Paper,
который будет:
- проверять пароль при входе игрока (сверяясь с той же базой `tgauth.db`)
- слать уведомление о входе в Telegram через chat_id из этой же таблицы
